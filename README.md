# Computer Vision and Deep Learning 

This repository contains assignments from the **Computer Vision and Deep Learning** course at UBB.

### Overview  

- **Lab 1:** Introduces the basics of NumPy operations on arrays and image manipulations (brightness adjustment, clipping, cropping, etc.).  
- **Lab 2:** Implements a simple **one-layer linear model** to make predictions on the CIFAR-10 dataset (visualization of how images are imprinted into the feature layers), covering dataset loading, manual model creation, and training.  
- **Lab 3:** Explores image filtering techniques, explains their functionality, introduces **transfer learning**, and compares models trained from scratch vs. pre-trained models.  
- **Lab 4 & 5:** Focus on a larger project using **UNet** to segment images of people's faces into three areas (hair, face, and background), utilizing PyTorch's **DataLoader** and **Model** classes, with **WandB** for parameter optimization.
